Privacy Policy

Last updated: September 2026 · v1.3.0

Short and honest: this gateway stores almost nothing. Here is exactly what happens with data.

Overview

This site is a static documentation site plus a serverless API running on Cloudflare Pages. There are no user accounts, no sign-ups and no third-party analytics scripts. We do not build advertising profiles and we do not sell data — there is no data to sell.

What is stored in your browser

Your theme (light/dark) and language (Bangla/English) choices are saved in your browser’s localStorage so the site remembers them. Playground request history and the chatbot conversation live only in your current browser tab/session and disappear when you clear them or close the tab. None of this is transmitted to us for tracking.

Chat messages

When you send a prompt to the gateway (playground, chatbot, /ask or Telegram), the gateway forwards it to the upstream AI provider to generate a reply. The gateway itself does not persist your prompts or the replies. Storage, logging and retention policies of the upstream provider you are using apply on their side — review them before sending sensitive content.

API keys

Provider API keys live exclusively in server-side environment variables on Cloudflare. They are never embedded in pages, never sent to browsers, and never included in the public source code. The env-setup page generates a local import file entirely inside your browser — keys typed there never leave your device.

Third parties

Hosting and edge delivery: Cloudflare (their network processes request metadata by necessity). AI generation: whichever provider answers your request (OpenRouter, OpenCode Zen, Poolside AI or your custom endpoint). The Admin Panel talks directly to GitHub’s API with the token you paste — that token stays in your browser.

Changes to this policy

Material changes will be listed in the changelog with a new version number. Questions or concerns? Open an issue on the public GitHub repository — it is the fastest way to reach the maintainer.
