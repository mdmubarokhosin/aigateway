Changelog

Every version of the AI Gateway API — what shipped, when, and why it matters.

v1.4.0 Latest September 2026

Every page, one design

  • All 15 pages now share the home design: aurora hero, floating light particles, gradient title accent and soft pill eyebrows
  • Env Setup page repaired: proper primary "Generate & download" button, polished key inputs with focus glow
  • Docs/guide/endpoints headings get gradient ticks; codeblocks lift on hover; table rows highlight
  • Scroll-reveal extended to code blocks, callouts and tables — with a safety net so content can never stay hidden
  • prefers-reduced-motion respected; print stylesheet for clean paper output
v1.3.0 September 2026

Design & Experience Upgrade

  • Aurora hero animation, floating light particles and animated gradient text
  • Live stats band (models, providers, error codes, uptime) with count-up numbers
  • Scrolling model marquee pulled from the live /models catalog
  • Rich footer: social icons, live status pill, quick theme/language controls, legal links
  • Ctrl+K command palette, back-to-top button and reading progress bar
  • Testimonials + FAQ sections, scroll-reveal animations on every card
  • New pages: Changelog, Privacy, Terms · beautified 404 · PWA manifest
v1.2.0 September 2026

Deep Failover + Admin PUSH

  • Deep model-level failover: a failing model makes the gateway try EVERY other model of that provider, then the next provider and all of its models — cycling until a reply
  • Admin panel 🚀 PUSH button commits site/providers/knowledge config straight to GitHub from the browser
  • wrangler.toml removed — dashboard Variables & Secrets import works again
  • Final cloudflare-env-import.env: import once, never hand-edit again
v1.1.0 September 2026

Multi-language + Admin CRUD

  • Full Bangla/English interface with Noto Serif Bengali typography everywhere
  • Admin panel: full CRUD over providers, models, site config and knowledge base
  • GET-style chat /api/v1/chat?prompt=… + /ask shortcut routes
  • Telegram bot webhook + on-site chatbot with markdown rendering
v1.0.0 September 2026

First Public Release

  • Express-style middleware API on Cloudflare Pages Functions (Hono runtime)
  • OpenRouter, OpenCode Zen, Poolside AI + zero-code custom providers
  • Automatic provider failover, typed error codes, per-IP rate limits
  • Landing page + 12 feature pages: docs, endpoints, models, playground, guide, status and more
