Why this gateway

Everything a production AI API needs

Built on Hono for Cloudflare Pages Functions, runnable anywhere Node.js 18+ runs.

Multi-provider routing

Switch provider or model per request with a single JSON field. Same response shape no matter who answers, so client code never changes.

Automatic provider failover

If one provider errors — rate limit, timeout, outage — the gateway instantly retries the next configured provider and keeps cycling until a response arrives. Zero code in your app.

Keys never leave the server

Provider API keys live in server environment variables. Browsers and clients only ever talk to your gateway — never to upstream providers.

Zero-code custom providers

Point CUSTOM_BASE_URL at any OpenAI-compatible server — OpenAI, DeepSeek, Ollama, LM Studio, vLLM — and it becomes a first-class provider.

Typed errors & rate limits

Upstream failures map into one consistent envelope with 16 typed codes, per-IP sliding-window limits, and Retry-After hints on 429s.

One .env controls everything

App name, version, providers, failover rounds — all env-driven. Change .env once and every page, endpoint and response reflects it after redeploy.

How it works

Three steps from request to reply

01 — Request

You send one JSON call

Your app posts a message (or a full multi-turn messages[] array) to your gateway, optionally naming a provider and model.

02 — Gateway

Validate, route, protect

The gateway validates input, applies rate limits and CORS, attaches the right server-side API key, and forwards to the chosen upstream provider.

03 — Normalized reply

One predictable envelope

You always get {success, provider, reply, model, usage} — or a typed error with an actionable message and retry hints.

Quick start

Call it from anywhere

The base URL below is auto-detected from your current address — the same snippet works on localhost and in production.

bash
curl -X POST https://YOUR-DOMAIN/api/v1/chat \
  -H "Content-Type: application/json" \
  -d '{
    "message": "What is the meaning of life?",
    "temperature": 0.7
  }'
javascript
const base = window.location.origin; // auto-detected API base URL
const res = await fetch(base + "/api/v1/chat", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    message: "Write a Go function that sums a slice of ints",
    max_tokens: 500,
  }),
});

const data = await res.json();
if (data.success) console.log(data.reply, "(served by", data.provider + ")");
else console.error(data.error.code, data.error.message);
python
import requests

res = requests.post(
    "https://YOUR-DOMAIN/api/v1/chat",  # auto-detected — this very domain
    json={
        "message": "What is the meaning of life?",
        "temperature": 0.7,
    },
    timeout=60,
)
data = res.json()
print(data["reply"] if data["success"] else data["error"]["message"])
