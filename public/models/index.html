Use any model right now

Copy a model id and send it with your request — the gateway routes it to the right provider and fails over automatically if that provider errors:

bash
curl -X POST https://YOUR-DOMAIN/api/v1/chat \
  -H "Content-Type: application/json" \
  -d '{
    "message": "Explain Go channels briefly",
    "provider": "openrouter",
    "model": "z-ai/glm-5.2:free"
  }'
